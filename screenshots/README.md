# Screenshots

`icon.png` and `demo.png` are generated by `swift Scripts/MakeHeroAssets.swift`
and committed for the README.

The following images are referenced by the README and need to be captured by
hand on a real Mac (set the repo up, run `Scripts/build.sh`, install the DMG):

- `menubar.png` — the colourful menu bar icon next to neighbouring icons
- `menu.png` — the dropdown menu opened from the menu bar
- `settings.png` — the Settings window with both layout pickers populated

Recommended size for these is around 1200–1600 px wide. Crop tightly, keep a
small amount of menu-bar / window-chrome padding for context, and save as PNG.
